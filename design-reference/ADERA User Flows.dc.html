BIDDER

Lands via SEO / referral → signs up, builds profile
Gets digest → opens feed, reads "why this fits"
Reads eligibility verdict, asks Q&A, runs win brief
Compares quotes → accepts → pays into escrow
Reviews proof per milestone → approves releases

ADERA
AI + platform
Ingests all sources daily → extracts, qualifies
Embeds profile ↔ tenders → matches + grounded explanations → TZ-aware notify
Eligibility chips per org_type · cited Q&A answers · checklist
Holds funds · opens engagement thread + milestones
Stores proof artifacts (immutable) · releases on approval · 48h dispute SLA
Feedback → ranking model · outcomes → corpus moat
FACILITATOR
local hands
Applies → ID + license vetting → monitored trial
— listed in marketplace —
Receives quote request → scopes milestones + price
Executes: buys docs, arranges CPO, site visit

$ ETB payout on approval · rating builds rank ↺
POSTER
verified business
KYB: license + TIN + signatory ID → Verified badge
Composes tender → AI lint → publishes → enters corpus
Answers bidder Q&A · sees views/saves

Receives bids via own opening process
Closes & awards → posts next tender ↺
ADMIN / OPS
founder
