# Proposals

Lightweight, ADR-lite way to propose an enhancement or correction **before**
writing code. Anyone on the team can open one — challenging the plan is
contribution, not noise.

**How:** copy `TEMPLATE.md` → `NNN-short-title.md` → open a PR → the founder
reviews. Merged proposals are decisions of record; strong architectural ones get
promoted to a real ADR in `adera-api/docs/ADRs/`.

Your **first task** on this repo is a proposal — see `FIRST_TASK.md`.
